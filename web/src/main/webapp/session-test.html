Test de la fonctionnalité Session avec l'annotation @Session

📌 Qu'est-ce que c'est?

L'annotation @Session permet d'annoter un argument de fonction dans une méthode d'une classe @Controller.

L'argument doit impérativement être de type Map<String, Object>. Vous pouvez accéder aux variables de HttpSession depuis ce Map.

⚙️ Comment ça marche?

1. À la réception de la requête:
→ HttpSession est copié dans un Map

2. Pendant l'exécution:
→ Le Map est passé en argument à la méthode

3. Après exécution:
→ Le contenu du Map est recopié dans HttpSession pour persister les changements

💻 Exemple de code

@Controller public class SessionController { @UrlMapping(url = "/session/ajouter") public ModelView ajouter( @RequestParam("nom") String nom, @Session Map<String, Object> session) { // Accès et modification de la session List<String> panier = (List) session.getOrDefault("panier", new ArrayList<>()); panier.add(nom); session.put("panier", panier); return new ModelView(...); } }
