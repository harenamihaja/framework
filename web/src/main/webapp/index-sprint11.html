Session Management avec @Session

📌 Session avec @Session

Vous avez implémenté l'annotation @Session qui permet d'accéder à la session HTTP via un Map<String, Object> dans vos méthodes de contrôleur.

  • Copie de HttpSession vers Map avant l'invocation
  • Copie de Map vers HttpSession après l'invocation
  • Support des redirects avec pattern "redirect:/url"
  • Exemple complet avec panier de produits
Voir la démo Lire la doc complète

⚙️ Architecture

Le système fonctionne avec 3 composants principaux:

  • FrontServlet - Gère la copie de session bidirectionnelle
  • SessionController - Exemple avec panier produits
  • Pages JSP - Interface pour tester la sessionBEDécision

🛒 Exemple d'utilisation

@UrlMapping(url = "/session/ajouter")
public ModelView ajouter(
    @RequestParam("nom") String nom,
    @Session Map<String, Object> session) {

    List<String> panier =
        (List) session.getOrDefault("panier",
        new ArrayList<>());
    panier.add(nom);
